## PilotDeck

PilotDeck is an open-source directory and discovery platform for AI tools and agents. In a landscape where new AI tools launch daily, PilotDeck provides a structured, community-curated way to find the right tool for your use case.

### The Problem

The AI tooling ecosystem is exploding. Developers waste hours sifting through Product Hunt posts, Twitter threads, and blog lists trying to find the right tool. PilotDeck brings order to the chaos.

### Key Features

- **Structured categories** — AI coding assistants, data tools, agents, RAG frameworks, and more
- **Side-by-side comparison** — compare tools on features, pricing, and integrations
- **Community ratings** — real developer feedback, not marketing copy
- **Integration guides** — step-by-step setup instructions for popular stacks
- **Weekly digest** — trending tools and notable updates
