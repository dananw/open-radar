## MoneyPrinterTurbo

MoneyPrinterTurbo is an automated short video generation tool. Give it a topic and it will:

1. Generate a script using an LLM
2. Search for relevant stock footage
3. Generate voiceover with text-to-speech
4. Add subtitles with precise timing
5. Compose everything into a finished video

### Why it matters

Content creation is time-consuming. MoneyPrinterTurbo compresses the video production pipeline from hours to minutes — while maintaining quality that's good enough for social media distribution.

### Key Features

- **Multi-provider LLM support** — OpenAI, Azure, local models
- **Multiple TTS engines** — Edge TTS, Azure TTS, local models
- **Smart footage matching** — AI-powered video search from Pexels and Pixabay
- **Customizable templates** — control aspect ratio, duration, style
- **Batch generation** — produce multiple videos from a topic list
- **Web UI** — Gradio interface for non-technical users
