## open-design

Open Design adalah alternatif open-source dan local-first untuk Claude Design yang berjalan sebagai native desktop app. Dengan 259+ skills dan 142+ design systems bawaan, tool ini memungkinkan developer dan designer membuat prototype untuk web, desktop, mobile, slides, images, hingga video langsung dari satu aplikasi. Mendukung integrasi dengan berbagai coding agent seperti Claude Code, OpenClaw, Codex, Cursor, Hermes, dan 17+ CLI lainnya.

### Why it matters

Bagi web developer, open-design menghilangkan ketergantungan pada tool design berbayar dan proprietary seperti Figma. Dengan pendekatan local-first, semua data tetap di mesin lokal — cocok untuk developer yang mengutamakan privasi dan kontrol penuh. Integrasi dengan coding agents membuat workflow design-to-code jadi seamless tanpa perlu export-import manual.

### Key Features

- **259+ Skills** — Kemampuan built-in yang bisa dipakai langsung tanpa konfigurasi tambahan
- **142+ Design Systems** — Koleksi design system siap pakai dari komunitas
- **Multi-format Export** — Export ke HTML, PDF, PPTX, dan MP4 dengan sandboxed preview
- **Agent Integration** — Bekerja dengan Claude Code, Codex, Cursor, OpenCode, Copilot, Hermes, Kimi, dan 17+ CLI lainnya
- **Local-first Architecture** — Semua data tersimpan lokal, tanpa cloud dependency

### Language & Stack

TypeScript · Apache-2.0

### Getting Started

```bash
# Clone repository
git clone https://github.com/nexu-io/open-design.git
cd open-design

# Install dependencies
npm install

# Run desktop app
npm run dev
```
